01지원 강의 안에서 시작됩니다

강의를 떠나지 않고, 언어만 바꾸세요.

SkillBridge는 지원되는 AI Academy 수업의 탐색·본문·학습 도구가 있는 원래 화면 안에서 필요한 언어를 더합니다.

버전 안내 GitHub 소스 릴리즈 v4.1.1의 현재 상태입니다. Chrome 웹 스토어 제출본은 아니며, 스토어에서는 기존 v1.0.1이 설치됩니다. 후속 CWS 버전과 대시보드 업로드는 코드 개발이 끝난 뒤 확정합니다. 미국에서는 현재 CWS 목록을 이용할 수 없어 GitHub 수동 설치 경로를 사용해야 합니다.검증 경계 자동 브라우저 픽스처는 Academy 라우팅과 Tutor 전송 경로를 검사하지만, 인증된 Academy 제출 후 화면과 로그인된 Puter의 최종 실사용 왕복 검증은 아직 주장하지 않습니다. 두 항목 모두 CWS 최종 게이트로 남아 있습니다.
