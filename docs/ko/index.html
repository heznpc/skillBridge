버전 안내 이 페이지는 아직 배포되지 않은 소스 후보 v4.0.0을 설명합니다. Chrome 웹 스토어에서는 기존 v1.0.1이 설치되며, 새 버전 공개는 검증이 끝날 때까지 중단된 상태입니다.
